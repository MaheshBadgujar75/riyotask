# Master India - Aluminium Manufacturing Excellence

A modern, high-performance landing page for **Masters India Private Limited** (Est. 1999), showcasing aluminium wire rods, flat rolled products, and AluShade roofing systems.

## ✨ Features

- **Butter-Smooth Scrolling**: Integrated with [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll) with debounced frame updates and zero-jank hover states.
- **Ultra-Optimized Visuals**: High-definition, web-optimized asset delivery (~2.8 MB total payload) for instant loading and 60fps/120fps hardware acceleration.
- **100% Fully Responsive**: Bespoke layouts tailored across Large Desktops, Laptops, Tablets, and Handheld Mobile devices down to 320px.
- **Mobile Drawer Navigation**: Sleek hamburger toggle navigation menu for compact screens.
- **Production Standard Code**: Clean HTML5 semantic markup and vanilla CSS with zero framework bloat.

## 🛠️ Tech Stack

- **HTML5** & **Vanilla CSS3**
- **Locomotive Scroll 4.1.4**
- **Google Fonts** (Plus Jakarta Sans)

## 🚀 Getting Started

Simply open `index.html` (or `riyotask.html`) in any modern web browser or serve it via any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx serve
npx serve .
```
